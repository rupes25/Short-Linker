ShortLinker 🔗

ShortLinker is a full-stack URL Shortener application currently under development.

The project is being built using Spring Boot, React, Docker, and other modern technologies. The main goal is to create a fast, scalable, and user-friendly platform for shortening and managing URLs.

🚀 Tech Stack
Backend: Java, Spring Boot
Frontend: React
Database: PostgreSQL / MySQL
Containerization: Docker
API: REST API
✨ Planned Features
🔗 Shorten long URLs
↪️ Redirect using shortened URLs
👤 User authentication & authorization
📊 URL analytics
📋 Manage shortened URLs
⏳ Link expiration
🔒 Secure APIs
🐳 Dockerized application
📱 Responsive React UI
